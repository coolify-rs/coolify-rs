# Compatibility assets

| Path | What | Generated by |
|---|---|---|
| `baseline/upstream-4.5.0-schema.sql` | upstream schema (`pg_dump --schema-only` of the 4.5.0 reference) | `pg_dump` (see docs/UPSTREAM_BASELINE.md) |
| `baseline/upstream-4.5.0-migrations.sql` | upstream `migrations` rows | `pg_dump` |
| `baseline/supported-migrations.txt` | migrations accepted by the schema guard | `coolify-port inventory --rev <rev> --write` |
| `api/upstream-routes.json` | static inventory of upstream `/api` routes | `coolify-port inventory --rev <rev> --write` |
| `api/reference-route-list-4.5.0.json` | `artisan route:list` from the official image | reference container |
| `mapping/registry.toml` | upstream → Rust traceability | maintained by hand, reviewed with architecture changes |
| `reference/` | compose file + seed script for the upstream reference instance | — |
| `diff/differential.py` | differential API test, upstream vs coolify-rs | — |

Secrets for the reference instance are generated into `reference/secrets/` (git-ignored) and are throwaway.
