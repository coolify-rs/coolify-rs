coolify-rs 4.6.0-rs.3 matches **Coolify 4.6.0**. It stops the sidebar from switching menus while you move around a resource.

coolify-rs is an independent reimplementation of Coolify in one Rust service. It is not affiliated with or endorsed by coolLabs.

## Upgrade from 4.6.0-rs.1 or 4.6.0-rs.2

Use the Upgrade button, or `upgrade.sh` as in [docs/INSTALL.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/INSTALL.md#upgrade). There are no database changes.

## Fixed

- **Sidebar menu.** Moving between the pages of an application, database, service or server showed the main menu for a moment and replayed the menu's slide-in on every click. The resource menu now stays, the clicked entry is highlighted at once, and the slide plays only when you open or leave a resource, as in Coolify.
- From 4.6.0-rs.2: **terminal behind a domain.** The terminal works when the dashboard is reached through the instance domain (the proxy sends `/terminal/ws` to port 6002).

## Install or migrate

On a clean server, or on a Coolify 4.6.0 server, as root:

```bash
curl -fsSL https://github.com/coolify-rs/coolify-rs/releases/latest/download/install.sh | sudo bash
```

See [docs/INSTALL.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/INSTALL.md) and [docs/MIGRATING.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/MIGRATING.md). Read [docs/KNOWN_LIMITATIONS.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/KNOWN_LIMITATIONS.md) before you switch.
