coolify-rs 4.7.6-rs.1 matches **Coolify 4.7.6**, the current Coolify release. If your Coolify updates itself, this is the release that can take it over.

coolify-rs is an independent reimplementation of Coolify in one Rust service. It is not affiliated with or endorsed by coolLabs.

## About Coolify 4.7.6

Coolify 4.7.6 is a security release for PHP, nginx and Node.js inside Coolify's own container image. coolify-rs runs none of them: its image is a Debian base with the coolify-rs binary, `curl` and `openssh-client`. Coolify 4.7.6 changes no database schema and no application behaviour, so coolify-rs needs no code changes for it. This release only declares Coolify 4.7.6 as the version coolify-rs takes over and gives back to.

## Changed

- **Dependency security updates.** The SMTP library (lettre 0.11.24) fixes several advisories, among them SMTP command injection through message content and STARTTLS reply injection. The plugin runtime (wasmtime 50.0.3) fixes crashes and unbounded memory growth that a plugin could cause, and the URL parser (url 2.5.9) fixes a stack overflow. Upgrading is recommended.

## Upgrade from 4.7.5-rs.1 or 4.7.5-rs.2

Use the Upgrade button, or `upgrade.sh` as in [docs/INSTALL.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/INSTALL.md#upgrade). There are no database changes.

From 4.6.0-rs.1 to 4.6.0-rs.5, upgrade the same way: on its first start, coolify-rs applies Coolify 4.7's 27 schema changes to your database, as Coolify's own upgrade would. From then on only Coolify 4.7.6 can take the database back.

## Migrate from Coolify 4.7.6

Back up, run the dry-run check, then run the installer on your Coolify server. It keeps your database, secrets, SSH keys, proxy and running resources, and you can go back to Coolify 4.7.6 the same way: [docs/MIGRATING.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/MIGRATING.md).

On Coolify 4.7.5 or older: upgrade Coolify to 4.7.6 first, then migrate.

```bash
curl -fsSL https://github.com/coolify-rs/coolify-rs/releases/latest/download/install.sh | sudo bash
```

Read [docs/KNOWN_LIMITATIONS.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/KNOWN_LIMITATIONS.md) before you switch.
