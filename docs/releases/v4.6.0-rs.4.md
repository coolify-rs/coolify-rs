coolify-rs 4.6.0-rs.4 matches **Coolify 4.6.0**. It opens the plugin registry: Settings → Plugins now lists the first-party plugins, and an instance admin can install them from there.

coolify-rs is an independent reimplementation of Coolify in one Rust service. It is not affiliated with or endorsed by coolLabs.

## Upgrade from 4.6.0-rs.1, 4.6.0-rs.2 or 4.6.0-rs.3

Use the Upgrade button, or `upgrade.sh` as in [docs/INSTALL.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/INSTALL.md#upgrade). There are no database changes.

## New

- **Plugin registry.** The catalogue under Settings → Plugins reads the signed index of [coolify-rs/plugins](https://github.com/coolify-rs/plugins). This release ships the registry's signing key, so the catalogue loads instead of answering "could not fetch …/main/dist/index.json". Each install shows the capabilities it grants, and the plugin's file is checked against the index before it runs. The first plugins:
  - `coolify-rs/alerts`: sends failed deployments, backups and scheduled tasks, unreachable servers and expiring certificates to ntfy, Google Chat, PagerDuty or Opsgenie.
  - `coolify-rs/deploy-chains`: deploys the applications that depend on an application after it deploys successfully.
  - `coolify-rs/delivery-metrics`: the four DORA metrics per team and per application, with CSV exports.
  - `coolify-rs/healthchecks`: pings Healthchecks.io for every scheduled task and backup, so a job that stops running raises an alarm.
  - `coolify-rs/deploy-stats`: counts successful and failed deployments per team.

  After installing, switch a plugin on for a team under Team → Plugins. See [docs/PLUGINS.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/PLUGINS.md).

## Earlier fixes in 4.6.0

- From 4.6.0-rs.3: **sidebar menu.** The resource menu stays while you move between a resource's pages.
- From 4.6.0-rs.2: **terminal behind a domain.** The terminal works when the dashboard is reached through the instance domain.

## Install or migrate

On a clean server, or on a Coolify 4.6.0 server, as root:

```bash
curl -fsSL https://github.com/coolify-rs/coolify-rs/releases/latest/download/install.sh | sudo bash
```

See [docs/INSTALL.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/INSTALL.md) and [docs/MIGRATING.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/MIGRATING.md). Read [docs/KNOWN_LIMITATIONS.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/KNOWN_LIMITATIONS.md) before you switch.
