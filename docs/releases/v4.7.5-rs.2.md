coolify-rs 4.7.5-rs.2 matches **Coolify 4.7.5**.

coolify-rs is an independent reimplementation of Coolify in one Rust service. It is not affiliated with or endorsed by coolLabs.

## Upgrade from 4.7.5-rs.1

Use the Upgrade button, or `upgrade.sh` as in [docs/INSTALL.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/INSTALL.md#upgrade). There are no database changes.

From 4.6.0-rs.1 to 4.6.0-rs.5, upgrade the same way: on its first start, coolify-rs applies Coolify 4.7's 27 schema changes to your database, as Coolify's own upgrade would. From then on only Coolify 4.7.5 can take the database back.

## Changed

- **Umami** in the service catalogue is now version 3.5.0 (was 3.0.3). Umami 3.5.0 runs its database migrations on start and needs `APP_SECRET`, which the template sets. It also removed Umami's public `/api/config` endpoint. Existing Umami services keep their image until you change it; the catalogue only affects new services.
- **Newer built-in templates are kept.** coolify-rs still downloads Coolify's service catalogue for upstream's template updates, but a template that coolify-rs ships with a later update date than the downloaded one now stays as coolify-rs ships it, instead of reverting to the older version.

## Install or migrate

On a clean server, or on a Coolify 4.7.5 server, as root:

```bash
curl -fsSL https://github.com/coolify-rs/coolify-rs/releases/latest/download/install.sh | sudo bash
```

See [docs/INSTALL.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/INSTALL.md) and [docs/MIGRATING.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/MIGRATING.md). Read [docs/KNOWN_LIMITATIONS.md](https://github.com/coolify-rs/coolify-rs/blob/main/docs/KNOWN_LIMITATIONS.md) before you switch.
